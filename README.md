# 法定速度よみ（hotei-sokudo）

道路（一般道路・高速道路）と車の種類（普通自動車・原付・大型トラック・けん引 など）を見て、標識などが無いときの最高速度（法定速度）を当てる1日5問の学習ゲーム。正解したら、どの決まり（一般道路・原付・高速道路・けん引と緊急の特例）かも選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/hotei-sokudo/>

- 中身は道路交通法施行令の第11条（最高速度）・第12条（最高速度の特例）・第27条（高速自動車国道の最高速度）に書いてあることだけです（e-Gov 法令検索 <https://laws.e-gov.go.jp/law/335CO0000000270> で読んだ現行の条文）。
- 問題の道路や車は練習のための例です。
- このゲームは運転の助言や、公式の情報の代わりではありません。実際の道では標識・標示に従い、決まりは法令や警察の案内で確かめてください。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。結果の画面で遊ぶ人が「Xで投稿」「LINEで送る」を押したときだけ、回の番号・日付と成績の印（問題・答えは入れない）がそのサービスに渡ります。
